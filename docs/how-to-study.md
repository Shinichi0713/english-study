# 勉強法

## ✅ TOEIC高得点のための戦略

| ----- | --------------------------------- |
| 600点 | 単語＋文法＋基本リスニング        |
| 700点 | パート対策＋速読                  |
| 800点 | 音読・シャドーイング＋全文法理解  |
| 900点 | 精聴/精読＋演習の質向上＋時間管理 |

---

## ✅ リスニング学習法（L 450+を目指す）

### ✨ TOEIC最強：シャドーイング（音声に合わせて発声）

効果

* 発音 → リスニング力UP
* 音の連結、脱落、弱形の感覚が掴める

おすすめ素材

* 公式問題集音声
* TED、BBC Learning English（上級）

---

### 📌 ディクテーション（書き取り）

* 聞き取れない原因を発見
* 短文でOK、毎日5分で十分

---

### 🎯 パート別対策

| Part     | 対策                                    |
| -------- | --------------------------------------- |
| Part 1   | 写真描写のよく出る語句暗記              |
| Part 2   | 返答パターン暗記（Yes/No以外の答え）    |
| Part 3&4 | 先読み習慣 + 内容より**情報特定** |

✅ リスニングは**音を理解 → 意味理解**の順。

英語を日本語に訳さず**イメージで理解**する癖をつける。

---

## ✅ リーディング学習法（R 400+）

### 📖 1. 文法は短期で固める（Grammarポイント集中）

出る順:

1. 語彙/品詞
2. 動詞/態（二重動詞、時制）
3. 関係詞
4. 分詞・不定詞
5. 前置詞

→ 「文法特急」「公式問題集」などで**解説を理解→例文暗唱**

---

### 🏃‍♂️ 2. 速読トレーニング

* 読めない＝知らない単語 or 語順処理が遅い
* **スラッシュリーディング**練習

例:

```
The manager / will review your request / by Friday.
```

---

### 📌 3. パート別戦略

| Part   | コツ                               |
| ------ | ---------------------------------- |
| Part 5 | 公式問題集で**パターン暗記** |
| Part 6 | 文脈理解＋語彙                     |
| Part 7 | スキミング＋スキャニング徹底       |

✓ 最初はPart 5 → Part 7の順で取り組む

✓ タイムマネジメント練習必須（75分）

---

## ✅ 参考学習スケジュール

| 時間      | 内容                   |
| --------- | ---------------------- |
| 毎日20min | シャドーイング         |
| 毎日20min | 文法＆単語             |
| 週2       | 公式問題集 2パート解く |
| 週末      | 模試＋復習             |

**復習 > 量**

間違いノートを作ると伸びる速度が倍になります。

## ✅ モチベーション管理術

* スコア表を壁に貼る

* AI（ChatGPT）で英文要約/添削してもらう

あなたの場合、AIを活用して

* シャドーイング添削
* 音声読み上げ
* 文法質問
* 語彙例文生成

などに使うと最速で伸びます。
