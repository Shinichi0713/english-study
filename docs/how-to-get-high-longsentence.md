## ✅ 長文対策で最も効果が高い学習法

### 1. **スキミング（ざっと読む）→ スキャニング（探す）**

長文は **すべて訳そうとすると時間切れ**になります。

**①全体の主旨をつかむ（スキミング）**

* タイトル・最初の文・段落最初の文を読む
* 「誰が・何を・なぜ」だけ意識

**②設問で聞かれた情報を探す（スキャニング）**

> 読まない勇気が得点UPに繋がる

---

### 2. **センテンスごとのスラッシュリーディング**

英語語順のまま理解する訓練です👇

例

```
The manager / will review your request / by next Monday.
```

→ 日本語語順に戻す癖を減らすことで

読むスピードと理解度が向上します。

---

### 3. **精読 + 多読の両方を行う**

| 方法 | 目的                  |
| ---- | --------------------- |
| 精読 | 文構造・文法徹底理解  |
| 多読 | スピード + 文脈理解力 |

> 精読だけ→遅い
>
> 多読だけ→誤読しやすい
>
> **両輪が必要**

---

### 4. **重要語彙・表現の「復現学習」**

長文で見た

* 接続詞（However / Although / Therefore）
* 重要表現（be likely to / due to / result in）

を**必ず辞書＋ノートで確認**

> 長文は語彙と文法の宝庫

---

### 5. **音読・シャドーイング**

音声がある教材では必須。

読むスピード＝頭の中の音声処理速度なので、

* 目で読む
* 声に出す
* 音声と一緒に読む（シャドーイング）

これで**長文処理スピードが劇的に上がります**

---

## ✅ 学習ステップ例（1長文ごと）

1. 先に設問を読む
2. スキミングで概要掴む
3. 問題を意識しながら本文読む
4. 間違い分析
5. 語彙・文法確認
6. 音読5回 → シャドーイング

→ **これを繰り返すと飛躍的に伸びます**
